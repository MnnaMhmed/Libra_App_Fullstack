# Libra — React Frontend Only

A standalone React rebuild of the supplied Libra Library Management UI. It does not call an API, require a backend, or depend on a server-side database. All app data is stored in the browser using `localStorage`.

## Requirements
- Node.js 18+

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Demo account
- Email: `admin@libra.com`
- Password: `Admin@123`

You can also create a local account from the Register screen.

## Included modules
- Dashboard with collection statistics, borrowing trend, category distribution, recent activity, and popular books
- Books: browse, search, filter, details, add, edit, delete, and borrow
- Members, authors, publishers, categories, and users: local CRUD, search, and status filtering
- Borrowing: create borrowing records, edit due dates, return books, search, and filter overdue/returned/borrowed records
- Activity logs generated by local create/update/delete actions
- Wishlist, profile editing, light/dark theme, responsive navigation, login, and registration

## Local data behavior
- First launch seeds sample records so every module is populated.
- Changes persist in the current browser profile under `libra_react_database_v1`.
- Sign-in state is stored separately under `libra_react_user_v1`.
- Use the browser's site data controls to clear the local demo database and restore the initial sample data.

## Important
This is a frontend-only demo. Authentication and roles are simulated in the browser and are not secure. Data is local to the browser/device and is not shared with other users or devices. No ASP.NET Core endpoint, API URL, HTTP client, or backend service is used.
